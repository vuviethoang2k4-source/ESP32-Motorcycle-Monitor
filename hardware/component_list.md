\# Component List



\## 1. Main Components



| No. | Component | Quantity | Function |

|---|---|---:|---|

| 1 | ESP32-S3 development board | 1 | Main controller, WiFi connection, Blynk communication |

| 2 | GPS NEO-8M module | 1 | Measure speed and GPS location |

| 3 | MPU6050 module | 1 | Detect vibration or abnormal movement |

| 4 | Buzzer | 1 | Local alarm and find motorcycle function |

| 5 | LED | 1 or more | Visual warning |

| 6 | Resistor | As needed | Current limiting for LED |

| 7 | Breadboard | 1 | Prototype testing |

| 8 | Jumper wires | As needed | Circuit connection |

| 9 | USB cable or adapter | 1 | Power supply for testing |



\## 2. Current Development Scope



In the current phase, the system focuses on:



```text

ESP32-S3 + GPS NEO-8M + MPU6050 + Blynk App
